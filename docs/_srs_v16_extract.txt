1 Introduction  The Scout is a four-wheeled Unmanned Ground Vehicle (UGV) designed to support both teleoperated and autonomous missions. There are different software systems that work together to make scout operational and reliable. This document covers all the software requirements right from powering ON the vehicle to powering OFF, including all the required safety and fall back requirements .  1.1 Scope  The scope of this System & Software Requirement Specification is to tell what different software should do to fulfill the user requirement. This document will act as a reference, and guide the engineers to achieve the goals defined in the User Requirement Specification.  The Scout Platform shall be developed in five incremental modes, each mode having advanced features compared to the prior modes. Refer Scout_td0_User_Requirements, Sec 5.2 to know about the four autonomy modes. The entire scout platform’s requirement are categorized into 3 areas for each of the five modes: a) Core operations b) Operator Interface c) Safety & Fallback There are  7 software as part of 5 subsystems and configuration of 1 subsystem, involved in the development of this platform, which are: a) Orion - MC: Configuration on Motor controller  b) Nexus - VCU: Vehicle control software on VCU c) Helios- HC: UGV remote control software on Hand controller  d) Atlas- MC: Mission computer software on Main Compute  e) Helios- OBD: HMI (Onboard display) software on Secondary compute  f) Helio-GCS: UGV control, monitoring and mission planning software on GCS g) Atlas-Vision: Computer Vision & Machine Learning software on Main compute h) Iris-Telematics: Logging & telemetry software on along with Motor controller configuration Secondary compute  Note:-  Nexus : Embedded application category   Atlas : Mission and Autonomy application category   Helios : Human machine interface category   Iris : Telemetry, Log management, OTA, MC online Configuration category   Orion : Offline Configuration category   1.2 Reference ● Scout User Requirements : Scout_td0_User_Requirements_v1.2_beta  dated 24th June, 2026
