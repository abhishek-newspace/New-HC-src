Release Versioning Rules
The release version shall follow the format:
vMajor.Minor.Patch (e.g., v1.0.0)
Version Component
When to Increment
Major
Increment when a new operational mode is introduced (e.g., transition from Mode B to Mode C).
Minor
Increment when the release includes one or more new features 
Patch
Increment when the release contains modifications to existing features and TIR fixes.
