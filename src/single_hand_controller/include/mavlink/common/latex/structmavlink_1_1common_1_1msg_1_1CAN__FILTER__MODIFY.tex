\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1CAN__FILTER__MODIFY}{CAN\+\_\+\+FILTER\+\_\+\+MODIFY}} message. 

Modify the filter of what CAN messages to forward over the mavlink. This can be used to make CAN forwarding work well on low bandwidth links. The filtering is applied on bits 8 to 24 of the CAN id (2nd and 3rd bytes) which corresponds to the Drone\+CAN message ID for Drone\+CAN. Filters with more than 16 IDs can be constructed by sending multiple \mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1CAN__FILTER__MODIFY}{CAN\+\_\+\+FILTER\+\_\+\+MODIFY}} messages.
