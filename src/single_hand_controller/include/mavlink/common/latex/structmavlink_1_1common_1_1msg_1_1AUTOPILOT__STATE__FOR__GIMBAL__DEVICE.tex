\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1AUTOPILOT__STATE__FOR__GIMBAL__DEVICE}{AUTOPILOT\+\_\+\+STATE\+\_\+\+FOR\+\_\+\+GIMBAL\+\_\+\+DEVICE}} message. 

Low level message containing autopilot state relevant for a gimbal device. This message is to be sent from the autopilot to the gimbal device component. The data of this message are for the gimbal device\textquotesingle{}s estimator corrections, in particular horizon compensation, as well as indicates autopilot control intentions, e.\+g. feed forward angular control in the z-\/axis.
