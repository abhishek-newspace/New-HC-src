\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1GIMBAL__MANAGER__SET__PITCHYAW}{GIMBAL\+\_\+\+MANAGER\+\_\+\+SET\+\_\+\+PITCHYAW}} message. 

Set gimbal manager pitch and yaw angles (high rate message). This message is to be sent to the gimbal manager (e.\+g. from a ground station) and will be ignored by gimbal devices. Angles and rates can be set to NaN according to use case. Use MAV\+\_\+\+CMD\+\_\+\+DO\+\_\+\+GIMBAL\+\_\+\+MANAGER\+\_\+\+PITCHYAW for low-\/rate adjustments that require confirmation.
