\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1PARAM__EXT__SET}{PARAM\+\_\+\+EXT\+\_\+\+SET}} message. 

Set a parameter value. In order to deal with message loss (and retransmission of \mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1PARAM__EXT__SET}{PARAM\+\_\+\+EXT\+\_\+\+SET}}), when setting a parameter value and the new value is the same as the current value, you will immediately get a PARAM\+\_\+\+ACK\+\_\+\+ACCEPTED response. If the current state is PARAM\+\_\+\+ACK\+\_\+\+IN\+\_\+\+PROGRESS, you will accordingly receive a PARAM\+\_\+\+ACK\+\_\+\+IN\+\_\+\+PROGRESS in response.
