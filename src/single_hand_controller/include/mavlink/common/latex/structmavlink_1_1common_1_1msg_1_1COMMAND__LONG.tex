\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1COMMAND__LONG}{COMMAND\+\_\+\+LONG}} message. 

Send a command with up to seven parameters to the MAV. \mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1COMMAND__INT}{COMMAND\+\_\+\+INT}} is generally preferred when sending MAV\+\_\+\+CMD commands that include positional information; it offers higher precision and allows the MAV\+\_\+\+FRAME to be specified (which may otherwise be ambiguous, particularly for altitude). The command microservice is documented at \href{https://mavlink.io/en/services/command.html}{\texttt{ https\+://mavlink.\+io/en/services/command.\+html}}
