\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1LOG__REQUEST__LIST}{LOG\+\_\+\+REQUEST\+\_\+\+LIST}} message. 

Request a list of available logs. On some systems calling this may stop on-\/board logging until \mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1LOG__REQUEST__END}{LOG\+\_\+\+REQUEST\+\_\+\+END}} is called. If there are no log files available this request shall be answered with one \mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1LOG__ENTRY}{LOG\+\_\+\+ENTRY}} message with id = 0 and num\+\_\+logs = 0. \mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1LOG__ENTRY}{LOG\+\_\+\+ENTRY}} messages can start with id 1 or 0. The ground station needs to be able to process either.
