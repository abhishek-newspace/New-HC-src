\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1ATTITUDE__TARGET}{ATTITUDE\+\_\+\+TARGET}} message. 

Reports the current commanded attitude of the vehicle as specified by the autopilot. This should match the commands sent in a \mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1SET__ATTITUDE__TARGET}{SET\+\_\+\+ATTITUDE\+\_\+\+TARGET}} message if the vehicle is being controlled this way.
