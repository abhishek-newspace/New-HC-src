\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1PARAM__REQUEST__READ}{PARAM\+\_\+\+REQUEST\+\_\+\+READ}} message. 

Request to read the onboard parameter with the param\+\_\+id string id. Onboard parameters are stored as key\mbox{[}const char$\ast$\mbox{]} -\/$>$ value\mbox{[}float\mbox{]}. This allows to send a parameter to any other component (such as the GCS) without the need of previous knowledge of possible parameter names. Thus the same GCS can store different parameters for different autopilots. See also \href{https://mavlink.io/en/services/parameter.html}{\texttt{ https\+://mavlink.\+io/en/services/parameter.\+html}} for a full documentation of QGround\+Control and IMU code.
