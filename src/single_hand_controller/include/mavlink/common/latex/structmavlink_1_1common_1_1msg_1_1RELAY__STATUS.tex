\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1RELAY__STATUS}{RELAY\+\_\+\+STATUS}} message. 

Reports the on/off state of relays, as controlled by MAV\+\_\+\+CMD\+\_\+\+DO\+\_\+\+SET\+\_\+\+RELAY. Message streaming should be requested using MAV\+\_\+\+CMD\+\_\+\+SET\+\_\+\+MESSAGE\+\_\+\+INTERVAL. Note that it should not be sent on every relay state change to avoid flooding the link.
