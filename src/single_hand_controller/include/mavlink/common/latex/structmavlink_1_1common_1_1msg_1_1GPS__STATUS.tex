\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1GPS__STATUS}{GPS\+\_\+\+STATUS}} message. 

The positioning status, as reported by GPS. This message is intended to display status information about each satellite visible to the receiver. See message GLOBAL\+\_\+\+POSITION\+\_\+\+INT for the global position estimate. This message can contain information for up to 20 satellites.
