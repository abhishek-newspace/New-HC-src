\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1CAMERA__THERMAL__RANGE}{CAMERA\+\_\+\+THERMAL\+\_\+\+RANGE}} message. 

Camera absolute thermal range. This can be streamed when the associated \mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1VIDEO__STREAM__STATUS}{VIDEO\+\_\+\+STREAM\+\_\+\+STATUS}} {\ttfamily flag} field bit VIDEO\+\_\+\+STREAM\+\_\+\+STATUS\+\_\+\+FLAGS\+\_\+\+THERMAL\+\_\+\+RANGE\+\_\+\+ENABLED is set, but a GCS may choose to only request it for the current active stream. Use MAV\+\_\+\+CMD\+\_\+\+SET\+\_\+\+MESSAGE\+\_\+\+INTERVAL to define message interval (param3 indicates the stream id of the current camera, or 0 for all streams, param4 indicates the target camera\+\_\+device\+\_\+id for autopilot-\/attached cameras or 0 for MAVLink cameras).
