\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1CAMERA__IMAGE__CAPTURED}{CAMERA\+\_\+\+IMAGE\+\_\+\+CAPTURED}} message. 

Information about a captured image. This is emitted every time a message is captured. MAV\+\_\+\+CMD\+\_\+\+REQUEST\+\_\+\+MESSAGE can be used to (re)request this message for a specific sequence number or range of sequence numbers\+: MAV\+\_\+\+CMD\+\_\+\+REQUEST\+\_\+\+MESSAGE.\+param2 indicates the sequence number the first image to send, or set to -\/1 to send the message for all sequence numbers. MAV\+\_\+\+CMD\+\_\+\+REQUEST\+\_\+\+MESSAGE.\+param3 is used to specify a range of messages to send\+: set to 0 (default) to send just the the message for the sequence number in param 2, set to -\/1 to send the message for the sequence number in param 2 and all the following sequence numbers, set to the sequence number of the final message in the range.
