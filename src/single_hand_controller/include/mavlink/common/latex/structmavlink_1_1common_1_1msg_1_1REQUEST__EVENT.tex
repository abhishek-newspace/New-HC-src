\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1REQUEST__EVENT}{REQUEST\+\_\+\+EVENT}} message. 

Request one or more events to be (re-\/)sent. If first\+\_\+sequence==last\+\_\+sequence, only a single event is requested. Note that first\+\_\+sequence can be larger than last\+\_\+sequence (because the sequence number can wrap). Each sequence will trigger an \mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1EVENT}{EVENT}} or EVENT\+\_\+\+ERROR response.
