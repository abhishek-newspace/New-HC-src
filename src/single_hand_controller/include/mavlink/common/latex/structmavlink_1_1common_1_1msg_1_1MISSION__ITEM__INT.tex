\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1MISSION__ITEM__INT}{MISSION\+\_\+\+ITEM\+\_\+\+INT}} message. 

Message encoding a mission item. This message is emitted to announce the presence of a mission item and to set a mission item on the system. The mission item can be either in x, y, z meters (type\+: LOCAL) or x\+:lat, y\+:lon, z\+:altitude. Local frame is Z-\/down, right handed (NED), global frame is Z-\/up, right handed (ENU). NaN or INT32\+\_\+\+MAX may be used in float/integer params (respectively) to indicate optional/default values (e.\+g. to use the component\textquotesingle{}s current latitude, yaw rather than a specific value). See also \href{https://mavlink.io/en/services/mission.html}{\texttt{ https\+://mavlink.\+io/en/services/mission.\+html}}.
