\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1COMMAND__INT}{COMMAND\+\_\+\+INT}} message. 

Send a command with up to seven parameters to the MAV, where params 5 and 6 are integers and the other values are floats. This is preferred over \mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1COMMAND__LONG}{COMMAND\+\_\+\+LONG}} as it allows the MAV\+\_\+\+FRAME to be specified for interpreting positional information, such as altitude. \mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1COMMAND__INT}{COMMAND\+\_\+\+INT}} is also preferred when sending latitude and longitude data in params 5 and 6, as it allows for greater precision. Param 5 and 6 encode positional data as scaled integers, where the scaling depends on the actual command value. NaN or INT32\+\_\+\+MAX may be used in float/integer params (respectively) to indicate optional/default values (e.\+g. to use the component\textquotesingle{}s current latitude, yaw rather than a specific value). The command microservice is documented at \href{https://mavlink.io/en/services/command.html}{\texttt{ https\+://mavlink.\+io/en/services/command.\+html}}
