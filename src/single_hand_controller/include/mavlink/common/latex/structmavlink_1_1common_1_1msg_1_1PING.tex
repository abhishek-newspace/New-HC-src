\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1PING}{PING}} message. 

A ping message either requesting or responding to a ping. This allows to measure the system latencies, including serial port, radio modem and UDP connections. The ping microservice is documented at \href{https://mavlink.io/en/services/ping.html}{\texttt{ https\+://mavlink.\+io/en/services/ping.\+html}}
