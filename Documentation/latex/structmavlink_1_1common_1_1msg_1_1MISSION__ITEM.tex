\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1MISSION__ITEM}{MISSION\+\_\+\+ITEM}} message. 

\mbox{\hyperlink{structmavlink_1_1Message}{Message}} encoding a mission item. This message is emitted to announce the presence of a mission item and to set a mission item on the system. The mission item can be either in x, y, z meters (type\+: LOCAL) or x\+:lat, y\+:lon, z\+:altitude. Local frame is Z-\/down, right handed (NED), global frame is Z-\/up, right handed (ENU). NaN may be used to indicate an optional/default value (e.\+g. to use the system\textquotesingle{}s current latitude or yaw rather than a specific value). See also \href{https://mavlink.io/en/services/mission.html}{\texttt{ https\+://mavlink.\+io/en/services/mission.\+html}}.
