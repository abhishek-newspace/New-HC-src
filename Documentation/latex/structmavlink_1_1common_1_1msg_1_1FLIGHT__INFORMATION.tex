\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1FLIGHT__INFORMATION}{FLIGHT\+\_\+\+INFORMATION}} message. 

Flight information. This includes time since boot for arm, takeoff, and land, and a flight number. Takeoff and landing values reset to zero on arm. This can be requested using MAV\+\_\+\+CMD\+\_\+\+REQUEST\+\_\+\+MESSAGE. Note, some fields are misnamed -\/ timestamps are from boot (not UTC) and the flight\+\_\+uuid is a sequence number.
