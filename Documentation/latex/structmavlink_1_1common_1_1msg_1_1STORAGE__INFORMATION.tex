\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1STORAGE__INFORMATION}{STORAGE\+\_\+\+INFORMATION}} message. 

Information about a storage medium. This message is sent in response to a request with MAV\+\_\+\+CMD\+\_\+\+REQUEST\+\_\+\+MESSAGE and whenever the status of the storage changes (STORAGE\+\_\+\+STATUS). Use MAV\+\_\+\+CMD\+\_\+\+REQUEST\+\_\+\+MESSAGE.\+param2 to indicate the index/id of requested storage\+: 0 for all, 1 for first, 2 for second, etc.
