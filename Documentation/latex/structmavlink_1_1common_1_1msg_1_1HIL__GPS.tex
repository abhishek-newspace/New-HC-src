\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1HIL__GPS}{HIL\+\_\+\+GPS}} message. 

The global position, as returned by the Global Positioning System (GPS). This is NOT the global position estimate of the system, but rather a RAW sensor value. See message GLOBAL\+\_\+\+POSITION\+\_\+\+INT for the global position estimate.
