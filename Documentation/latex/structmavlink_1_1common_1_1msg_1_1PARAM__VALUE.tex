\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1PARAM__VALUE}{PARAM\+\_\+\+VALUE}} message. 

Emit the value of a onboard parameter. The inclusion of param\+\_\+count and param\+\_\+index in the message allows the recipient to keep track of received parameters and allows him to re-\/request missing parameters after a loss or timeout. The parameter microservice is documented at \href{https://mavlink.io/en/services/parameter.html}{\texttt{ https\+://mavlink.\+io/en/services/parameter.\+html}}
