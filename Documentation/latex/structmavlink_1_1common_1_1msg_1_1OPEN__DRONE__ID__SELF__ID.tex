\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1OPEN__DRONE__ID__SELF__ID}{OPEN\+\_\+\+DRONE\+\_\+\+ID\+\_\+\+SELF\+\_\+\+ID}} message. 

Data for filling the Open\+Drone\+ID Self ID message. The Self ID \mbox{\hyperlink{structmavlink_1_1Message}{Message}} is an opportunity for the operator to (optionally) declare their identity and purpose of the flight. This message can provide additional information that could reduce the threat profile of a UA (Unmanned Aircraft) flying in a particular area or manner. This message can also be used to provide optional additional clarification in an emergency/remote ID system failure situation.
