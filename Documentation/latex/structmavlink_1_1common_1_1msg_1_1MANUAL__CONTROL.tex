\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1MANUAL__CONTROL}{MANUAL\+\_\+\+CONTROL}} message. 

Manual (joystick) control message. This message represents movement axes and button using standard joystick axes nomenclature. Unused axes can be disabled and buttons states are transmitted as individual on/off bits of a bitmask. For more information see \href{https://mavlink.io/en/manual_control.html}{\texttt{ https\+://mavlink.\+io/en/manual\+\_\+control.\+html}}
