\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1ESC__STATUS}{ESC\+\_\+\+STATUS}} message. 

ESC information for higher rate streaming. Recommended streaming rate is $\sim$10 Hz. Information that changes more slowly is sent in \mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1ESC__INFO}{ESC\+\_\+\+INFO}}. It should typically only be streamed on high-\/bandwidth links (i.\+e. to a companion computer).
