\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1MISSION__CURRENT}{MISSION\+\_\+\+CURRENT}} message. 

\begin{DoxyVerb} Message that announces the sequence number of the current target mission item (that the system will fly towards/execute when the mission is running).
 This message should be streamed all the time (nominally at 1Hz).
 This message should be emitted following a call to MAV_CMD_DO_SET_MISSION_CURRENT or MISSION_SET_CURRENT.
\end{DoxyVerb}
