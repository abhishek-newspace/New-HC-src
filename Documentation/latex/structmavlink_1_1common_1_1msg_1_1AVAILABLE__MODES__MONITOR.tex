\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1AVAILABLE__MODES__MONITOR}{AVAILABLE\+\_\+\+MODES\+\_\+\+MONITOR}} message. 

A change to the sequence number indicates that the set of \mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1AVAILABLE__MODES}{AVAILABLE\+\_\+\+MODES}} has changed. A receiver must re-\/request all available modes whenever the sequence number changes. This is only emitted after the first change and should then be broadcast at low rate (nominally 0.\+3 Hz) and on change. See \href{https://mavlink.io/en/services/standard_modes.html}{\texttt{ https\+://mavlink.\+io/en/services/standard\+\_\+modes.\+html}}
