\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1PARAM__EXT__VALUE}{PARAM\+\_\+\+EXT\+\_\+\+VALUE}} message. 

Emit the value of a parameter. The inclusion of param\+\_\+count and param\+\_\+index in the message allows the recipient to keep track of received parameters and allows them to re-\/request missing parameters after a loss or timeout.
