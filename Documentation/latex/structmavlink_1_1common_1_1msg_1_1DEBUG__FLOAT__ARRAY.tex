\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1DEBUG__FLOAT__ARRAY}{DEBUG\+\_\+\+FLOAT\+\_\+\+ARRAY}} message. 

Large debug/prototyping array. The message uses the maximum available payload for data. The array\+\_\+id and name fields are used to discriminate between messages in code and in user interfaces (respectively). Do not use in production code.
