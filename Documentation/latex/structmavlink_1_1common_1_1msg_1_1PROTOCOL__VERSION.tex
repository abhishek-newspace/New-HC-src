\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1PROTOCOL__VERSION}{PROTOCOL\+\_\+\+VERSION}} message. 

Version and capability of protocol version. This message can be requested with MAV\+\_\+\+CMD\+\_\+\+REQUEST\+\_\+\+MESSAGE and is used as part of the handshaking to establish which MAVLink version should be used on the network. Every node should respond to a request for \mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1PROTOCOL__VERSION}{PROTOCOL\+\_\+\+VERSION}} to enable the handshaking. Library implementers should consider adding this into the default decoding state machine to allow the protocol core to respond directly.
