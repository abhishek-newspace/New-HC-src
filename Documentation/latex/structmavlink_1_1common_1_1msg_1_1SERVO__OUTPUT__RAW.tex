\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1SERVO__OUTPUT__RAW}{SERVO\+\_\+\+OUTPUT\+\_\+\+RAW}} message. 

Superseded by \mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1ACTUATOR__OUTPUT__STATUS}{ACTUATOR\+\_\+\+OUTPUT\+\_\+\+STATUS}}. The RAW values of the servo outputs (for RC input from the remote, use the \mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1RC__CHANNELS}{RC\+\_\+\+CHANNELS}} messages).
