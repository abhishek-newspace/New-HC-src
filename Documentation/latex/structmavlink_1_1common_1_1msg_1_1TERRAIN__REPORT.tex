\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1TERRAIN__REPORT}{TERRAIN\+\_\+\+REPORT}} message. 

Streamed from drone to report progress of terrain map download (initiated by \mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1TERRAIN__REQUEST}{TERRAIN\+\_\+\+REQUEST}}), or sent as a response to a \mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1TERRAIN__CHECK}{TERRAIN\+\_\+\+CHECK}} request. See terrain protocol docs\+: \href{https://mavlink.io/en/services/terrain.html}{\texttt{ https\+://mavlink.\+io/en/services/terrain.\+html}}
