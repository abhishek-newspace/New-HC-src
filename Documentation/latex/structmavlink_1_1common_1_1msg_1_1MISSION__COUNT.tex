\doxysubsection{Detailed Description}
\mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1MISSION__COUNT}{MISSION\+\_\+\+COUNT}} message. 

This message is emitted as response to \mbox{\hyperlink{structmavlink_1_1common_1_1msg_1_1MISSION__REQUEST__LIST}{MISSION\+\_\+\+REQUEST\+\_\+\+LIST}} by the MAV and to initiate a write transaction. The GCS can then request the individual mission item based on the knowledge of the total number of waypoints.
